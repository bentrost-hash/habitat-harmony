# Community launch kit

## Release gate

Before publishing the repository or site publicly, obtain written permission
from Villanelle to redistribute the normalized compatibility data. Keep the
original workbook private and retain attribution regardless of the outcome.

Suggested message:

> Hi Villanelle — I built a small, offline-first website called Habitat Harmony
> to make your Planet Zoo Data Chest compatibility data quicker to use on a
> second screen. It attributes and links back to your spreadsheet, preserves the
> distinction between enrichment and general compatibility, and will be open
> source for corrections. May I publish the normalized habitat dataset and a
> GitHub Pages version under that attribution? I will not distribute your
> original workbook, and I’m happy to add any credit, link, or license wording
> you prefer.

> Habitat Harmony lets you search an animal and instantly see enrichment
> partners, excellent matches, workable matches, compromises, and no-go pairs.

## Launch checklist

1. Receive and record permission for the normalized data.
2. Create a GitHub repository and set the appropriate visibility.
3. Commit the staged project; do not add `source-data.xlsx`.
4. Enable GitHub Pages using the included Actions workflow and verify the URL.
5. Replace both placeholders in the Reddit draft with the final links.
6. Check the current r/PlanetZoo self-promotion rules and post only if allowed.
7. Invite corrections through GitHub Issues; request game mode/settings and
   evidence for every data correction.
